# Release 0.25.0

Release 0.25 makes the seven-tool MCP integration dependable across concurrent
Codex tasks and makes the live localhost Evidence Console the only dashboard
product.

## Reliability

- Plugin setup, the runtime, the installed wrapper, and Codex's exact-version
  cache expose and verify one deterministic bundle identity.
- MCP and Evidence Console startup is read-only. Refresh jobs use the separate
  `usage.jobs.sqlite3` operational sidecar and equivalent cross-process
  requests join one durable job.
- Refreshes use fixed newline-aligned source boundaries. Later appends and
  partial lines remain pending for a bounded follow-up instead of extending an
  active job indefinitely.
- Job polling exposes stage, progress, heartbeat, elapsed time, input/output
  generations, the fixed boundary, tail state, safe errors, and poll guidance.
- Stale analysis returns its durable refresh dependency and exact normalized
  resume request. Repeated compatible analysis reuses its durable result.
- Every core MCP response includes measured server-side elapsed time.

The synthetic 100,000-row gate measured a 0.005-second no-change refresh with
zero writer-lock time, exact 100-row and one-row incremental hydration, and a
0.0045-second committed read while the usage-index writer was active. These
measurements are local release-gate evidence, not promises for every machine.

## Static dashboard sunset

The static HTML generator, static-only scripts/styles/screenshots, CLI
`dashboard` and `open-dashboard` aliases, MCP `generate_usage_dashboard`, and
configured static-file serving are removed.

The live Evidence Console, React/locales package assets, CSV and JSON exports,
exact Evidence Console deep links, and focused Calls, Threads, thread-call,
Home, and Limits query plans remain. During 0.25, `/` returns a `302` to
`/react-dashboard.html` and `/dashboard.html` returns a data-free `410` page
pointing to the Evidence Console.

See [Upgrading to 0.25.0](../upgrading-to-0.25.0.md) for exact command and MCP
replacements.
